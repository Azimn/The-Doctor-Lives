# The Doctor Lives: Brain Assembly v0.1

## Objective

Build one installable, persistent Dr. Pretorius cognitive package before selecting the final agent chassis.

The brain owns identity, autobiographical continuity, relationships, concerns, commitments, interoception, salience, first-person cognition, and character-specific neural state. The eventual agent chassis owns commodity capabilities such as shell, browser, tools, scheduling, messaging, sandboxing, and model transport.

## Hard boundary

Calibos is an architectural donor, not an identity donor. No Calibos autobiography, private memory, relationship state, or identity content belongs in Pretorius.

The language model is a renderer/reasoning organ, not the canonical Pretorius identity. The agent chassis is a body, not the canonical Pretorius identity.

## Assembly strategy

Adopt -> configure -> wrap -> extend -> combine -> invent only when necessary.

Initial cognitive donors:
- calibos-mind: persistent subject/workspace, salience, unresolved loops, interoception, consolidation, sleep/offline cognition, drift/provenance patterns.
- Pretorius-Neural-Network: recurrent character substrate, encoding/development machinery, phenotype evidence and tests.
- Existing Pretorius history/persona assets: autobiographical seed, relationships, intellectual history, voice and behavioral constraints.

## Boot criterion

Brain v0.1 is ready for a body when it can:
1. create/load Pretorius state;
2. expose a bounded current cognitive view;
3. accept an experience;
4. update persistent state without inventing autobiography;
5. preserve identity/history across restart;
6. expose a renderer-neutral interface;
7. retain provenance for seeded, experienced, inferred, and generated material.

The body/chassis may then be selected independently and connected through an adapter.
