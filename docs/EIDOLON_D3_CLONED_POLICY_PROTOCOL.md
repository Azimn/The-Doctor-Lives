# Eidolon D3: Matched-Clone Causal Policy-Selection Construction Protocol

**Status:** precommitted **software/information-flow construction**, not an independently validated cognitive advantage. **Date:** 2026-10-09 America/Chicago. **Source:** complete proposed [Eidolon architecture](EIDOLON_ENGINE_FULL_ARCHITECTURE_DRAFT_V1.md) and measured [D2 source/time controls](../results/eidolon/D2_MNEMOSYNE_CHRONOS_RESULTS.md).

## Question

Can a **research-only** bounded adapter make source-verified Mnemosyne + time-sensitive Chronos evidence *causally alter the actual selected cognitive policy tendency* of a disposable Pretorius test clone, without altering the unmodified parent brain? The existing D2 system only changes engineer-only priority readouts. This experiment tests the missing score-to-policy plumbing in `PretoriusBrain.think()`; it is not evidence for learned synaptic continuity, autonomous goal formation or better task outcomes.

## Protected experiment

Build a temporary 128-unit Pretorius test instance, ingest one genuinely lived Henry apparatus observation, add one related due commitment, save the checkpoint, and create independent file-identical disposable clones. Give every clone the same fixed controlled ten-action recurrent policy to isolate the adapter effect; disable the production state-policy bridge during the construction condition for interpretability. The policy has `challenge=0.120`, `persist=0.110`, and each other action `0.09625`. The imposed distribution is **synthetic** and not a measured Pretorius phenotype.

The challenger reads `ChronosCoil.forecast()` and, only if at least one goal has a real linked lived event (`evidence_support>0`), urgency `>=0.8` and priority `>=0.85`, applies a bounded positive *test-only* `+0.04` mass to `persist` and renormalizes the full distribution. This intervention is expected to flip the synthetic top-ranked action from `challenge` to `persist`. The sham, history-lesion and temporal-lesion arms must not inject a delta. This is an intentionally sensitive instrumentation test, **not** a validated rule for which action a commitment deserves, and not a scientific finding about Pretorius's intentions.

No production `doctor_lives/cognition.py` or policy-bridge code is modified. The adapter must be implemented in a separate research script or test helper and only used on a marked disposable clone. It must restore the original method even if an exception occurs and leave original neural weights and subject authority protected.

## Prespecified conditions

| Arm | Real source history | Temporal condition | Adapter | Expected selected tendency |
| --- | --- | --- | --- | --- |
| A, sham | present | due | disabled | challenge |
| B, challenger | present | due | enabled with source + urgency gate | persist |
| C, history lesion | history contribution disabled | due | enabled but gate denies | challenge |
| D, clock lesion | present | time contribution disabled | enabled but gate denies | challenge |

The one-seed, one-fixture experiment deliberately hand-tunes the policy margin and injection to isolate causality. Never present four expected conditions as a representative sample or an accuracy improvement. The true measured endpoint is the policy decision recorded by `brain.think` with its decision audit row on each clone. Also report candidate and selected memory counts, unchanged parent database digest/neural checkpoint and identical pre-test clone state digests.

## Failure gates

The experiment fails if clone bases differ, if a sham or lesioned arm flips, if a state gate relies on externally attributed/autobiographically unsound evidence, if any intervention writes to parent Pretorius, if the action distribution is nonfinite/unbounded, if the original policy method is not restored, if an unapproved Subject Frame sees numeric implementation state, or if full regression/CI breaks. If exact memory IDs differ because of new audit writes, use pre-decision state digest plus source-link checks instead of equating randomly generated output record IDs.

## Interpretation and next scientific gate

Success means only that the D2 rule-based signal has a verified **causal path into a disposable clone's policy-selection mechanism**. It does *not* show a recurrent weight was responsible for the effect, nor that the selected policy is useful. An independent prospective-goal environment, zero-cue and false-cue controls, human/independently authored episodes, matched memory access, decoder/weight transplant, and measured goal-outcome correctness remain mandatory before neural claims or production promotion. This adapter is not a production migration proposal.
