# Eidolon E5-P0B design gate — Grounded tool actions are not motivational tendencies

**Status:** prospective research design, NOT yet implemented or tested. **Date:** October 10, 2026. **Predecessor:** [E5-P0A's genuine but 0/6 cognitive policy outcomes](../results/eidolon/E5_P0A_NATIVE_NEURAL_ACTION_RESULTS_V01.md).

## The demonstrated bottleneck

E5-P0A sent *actual* native `PretoriusBrain.think()` and Noetic sparse W/decoder tendencies through a transparent ten-way-to-primitive translator. All four neural conditions completed 0/6 publicly authored world tasks while the explicitly task-scripted upper reference completed 6/6. Pretorius waited 35/36 decisions due to unavailable affordances. Noetic often `persist → resolve goal` without repairing/repositioning/reading. Its learned W lesion caused 0/36 categorical changes. No neural tendency mapped to positive `attribute`, making some evaluation objectives structurally inaccessible, rather than exposing an autonomous source-model failure.

This is an **abstraction mismatch**, not evidence that a better recurrent network would be conscious or could never plan. A motivational signal answers a different question from the executable action-plus-operand choice. Do not retune the old translator and attribute gains to neural learning.

## Proposed separated responsibilities

1. **World authority:** E5 LaboratoryWorld persists independent object/claim/commitment history, accepts or rejects actual primitive tool requests and audits replay. No agent self-reported completion counts as a repaired object.
2. **Subject-bounded observed state:** a versioned, audited public interface exposes interacted-with/observed objects and source attribution; it does not provide hidden predicates, arbitrary exact geometry or engineer-only event hashes. An agent must genuinely read a book to learn its content.
3. **Prospective task ledger:** explicit unresolved user/world commitments, due ticks, target objects, previous failed attempts and evidence provenance. This ledger is not a hidden benchmark answer key or a prewritten task solution. It may choose to withhold action or resume work after restart.
4. **Grounded tool proposal:** independent policy produces a set of executable `verb + operand` candidates and expected visible preconditions, **including `attribute`, `reject`, `wait`, `read`, `inspect`, `repair`, `move`, `bookmark`, `resolve`**. Require exact coverage; reject a test arm with unreachable required verbs *before* opening outcomes.
5. **Selection/ranking:** simple transparent public-text/commitment baseline, a matched learned tool-action ranker, and an optional **native/Noetic tendency-conditioned contribution** with fixed preregistered weight and no force-success fallback. Compare the same proposal generator and state budget with neural contribution ON and OFF, plus same-seed virgin W lesion. If the no-neural controller alone works, credit belongs to the planner, not the brain.
6. **Feedback and consolidation:** externally observed tool result updates the prospective ledger; only source-verified lived experience may enter owned autobiographical memory, never outside testimony simply because the controller believed it. Do not create artificial lived memories as a side effect of E5 authoring.

## Locked future audit requirements

**Before any new trial**, the experiment must prove positive and negative reachability of *all nine* laboratory primitive verbs, and demonstrate that a false external first-person claim cannot enter the lived ledger when action selection is adversarial. Report tool coverage and end-to-end task success separately. Build a development-only set that is *distinct from the exposed six E5-P0 cases*, and never use those six as independent held-out evidence.

**Baseline matrix:** no-op, public-text planner only, public-text planner + fixed native `PretoriusBrain.think()`, public-text planner + frozen E4-C Noetic W and decoder, same planner + exactly lesioned virgin W with unchanged decoder, and planner trained without neural input at equal supervision/compute. Score state outcomes, actual action paths, no-op/denial counts, premature goal closure, timeline persistence and provenance failures. Independently generated P1 outcomes require separately attested authorship and provenance; a SHA-256 does not by itself certify a blind suite.

**Causal evidence rule:** improved task outcome with a neural arm does not establish **learned recurrent necessity** unless its exact W replacement (with everything else and the model's readout frozen) removes the benefit across unseen tasks with meaningful margins and no added false-memory adoption.

**Implementation restriction:** E5-P0A's fixed mapping/results, E4 nulls and full experiment artifacts are frozen and preserved. The proposed P0B action planner is a **new candidate component**, not a refactoring that retroactively changes those measurements. Production Pretorius and Frankenstein Village are untouched pending a specific authenticated-world integration approval.
