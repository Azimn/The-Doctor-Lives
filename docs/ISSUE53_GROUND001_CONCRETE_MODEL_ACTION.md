# Issue #53 GROUND-001: Real model selection of typed action and operand

**Research branch:** research/living-laboratory-integration-issue53, draft PR #54.

**Problem from first actual trial:** the established recurrent Pretorius policy produced abstract tendencies such as approach. The former hand-weighted mapper determined the concrete action; removing neural weights changed 0/3 choices. The baseline nonneural controller also completed the world task. That established the persistence bridge but not independent object-action control.

**Implemented challenge:** a local, SHA-verified Qwen3-1.7B GGUF model is a replaceable **concrete actuator decoder** operating on The Doctor Lives' accepted source-scoped SubjectFrame. The Doctor Lives remains sole owner of identity, lived memories, commitments, neural state, policy records and autobiography. Pretorius-Laboratory is the only authorized world reducer. This is not an additional persisted character brain. It is nevertheless accurate to say the language model, not the existing recurrent abstract policy, makes the new concrete tool proposal.

The new actuator receives the same fixed higher-level task, a qualitative observation of the current laboratory state with a verified delivery receipt, first-person context generated by the accepted firewall, and a deliberately **non-ranked menu** of admissible operation+operand JSON objects. It must itself output an exact offered object. It cannot leave object selection to an oracle mapper. The model may select wait, inspect a floor, inspect a shelf, collect beaker fragments, or place collected fragments in a previously observed destination. Unrelated legal inspections are present as distractors; their authorization does not imply task relevance. The destination is not exposed until a corresponding subject-admitted floor observation exists. This is an epistemic bound, not the physical authority itself.

The host executes only an exactly offered and independently accepted operation with a fresh expected world revision. Verified action consequences are linked to event hash and admitted into the **disposable** Pretorius brain using the prior receipt admission port. Bad JSON, invented operands, unauthorized operations and invented facts are rejected without being credited as WAIT or task success. A legitimate WAIT is a distinct scored choice. An inspection receives an observation receipt and a separate admitted source record; observations alone do not mutate the physical glass.

## What this does and does not establish

When actual model CI succeeds technically, it establishes the concrete proposal mechanism runs on a real free local model and interacts with the existing authoritative lab. Individual task completion, invalid choices, goal-irrelevant legal inspections, abstention and failure should be scored from raw results, not predicted. Unit tests use an explicitly labelled deterministic FakeModel solely to test parsing, denial and world/memory transaction plumbing. Those tests are NOT real-model autonomy evidence.

The next causal experiment must compare a **frozen identical menu, world observation and task goal** with subject autobiography intact versus omitted or shuffled, using a clean renderer/model restart for each counterfactual. This is required to disentangle the effect of admissible source memory from action-menu restrictions and renderer inference. Multiple predeclared, independently reviewed tasks are required before claiming the model policy improves character continuity. A single successful glass cleanup is not generalization. The original recurrent substrate's unique causal contribution remains unproven even if the GGUF succeeds. No Sensus, Noetic, Eidolon, Village or production migration is authorized through this work.
