# Issue #53 GROUND-001: Real model selection of typed action and operand

**Research branch:** research/living-laboratory-integration-issue53, draft PR #54.

**Problem from first actual trial:** the established recurrent Pretorius policy produced abstract tendencies such as approach. The former hand-weighted mapper determined the concrete action; removing neural weights changed 0/3 choices. The baseline nonneural controller also completed the world task. That established the persistence bridge but not independent object-action control.

**Implemented challenge:** a local, SHA-verified Qwen3-1.7B GGUF model is a replaceable **concrete actuator decoder** operating on The Doctor Lives' accepted source-scoped SubjectFrame. The Doctor Lives remains sole owner of identity, lived memories, commitments, neural state, policy records and autobiography. Pretorius-Laboratory is the only authorized world reducer. This is not an additional persisted character brain. It is nevertheless accurate to say the language model, not the existing recurrent abstract policy, makes the new concrete tool proposal.

The new actuator receives the same fixed higher-level task, a qualitative observation of the current laboratory state with a verified delivery receipt, first-person context generated by the accepted firewall, and a deliberately **non-ranked menu** of complete operation-and-operand tokens. It must itself output an exact offered token, such as COLLECT|beaker:001 or OBSERVE|floor:sanctum. It cannot leave object selection to an oracle mapper. The model may select wait, inspect a floor, inspect a shelf, collect beaker fragments, or place collected fragments in a previously observed destination. Unrelated legal inspections are present as distractors; their authorization does not imply task relevance. The destination is not exposed until a corresponding subject-admitted floor observation exists. This is an epistemic bound, not the physical authority itself.

The model's complete token maps mechanically to the same typed host operation, without missing-field repair or a preselected target. The host executes only an exactly offered and independently accepted operation with a fresh expected world revision. Verified action consequences are linked to event hash and admitted into the **disposable** Pretorius brain using the prior receipt admission port. Bad JSON, invented operands, unauthorized operations and invented facts are rejected without being credited as WAIT or task success. A legitimate WAIT is a distinct scored choice. An inspection receives an observation receipt and a separate admitted source record; observations alone do not mutate the physical glass.

## What this does and does not establish

When actual model CI succeeds technically, it establishes the concrete proposal mechanism runs on a real free local model and interacts with the existing authoritative lab. Individual task completion, invalid choices, goal-irrelevant legal inspections, abstention and failure should be scored from raw results, not predicted. Unit tests use an explicitly labelled deterministic FakeModel solely to test parsing, denial and world/memory transaction plumbing. Those tests are NOT real-model autonomy evidence.

The next causal experiment must compare a **frozen identical menu, world observation and task goal** with subject autobiography intact versus omitted or shuffled, using a clean renderer/model restart for each counterfactual. This is required to disentangle the effect of admissible source memory from action-menu restrictions and renderer inference. Multiple predeclared, independently reviewed tasks are required before claiming the model policy improves character continuity. A single successful glass cleanup is not generalization. The original recurrent substrate's unique causal contribution remains unproven even if the GGUF succeeds. No Sensus, Noetic, Eidolon, Village or production migration is authorized through this work.

**Safety note:** this is local, trusted-operator research software. SQLite event hashes are tamper-evident under the host model, not cryptographic assurances against malicious filesystem access. No new network credentials, hosted agents or deployment permissions are granted.

**Promotion gate:** draft PR #54 is research-only. Do not merge directly to main unless independent holdouts, hostile-data review, atomicity/restart tests and the existing release safety gates pass.

## GROUND-001 live sequence, recorded negative results

The first live pinned-Qwen run at https://github.com/Azimn/The-Doctor-Lives/actions/runs/38092657996 selected an unrelated but legal third-shelf inspection, then produced a mixed-schema invalid collection request. World completion was false, the simple nonneural control completed, and only one source-backed observation was admitted. The raw trace is retained in the workflow artifact and the curated summary results/issue53/ground001_first_real_model_negative.json.

The uniform three-field JSON revision at https://github.com/Azimn/The-Doctor-Lives/actions/runs/38092943830 improved initial action selection: actual Qwen selected COLLECT beaker:001, the host committed collection, and one autobiographical action receipt was admitted. Its next model answer misassigned the observation target to the destination field, so the proposal was rejected. Physical goal completion remained false, whereas the strong nonneural comparator completed it.

The current v2 experiment replaces the brittle JSON-field presentation with a single exact-match *semantic action token* containing the complete operation and operand. No token is ever inserted on behalf of the model, invalid proposals still fail, and actual repeated-model evidence remains necessary. This is a **presentation and output-schema intervention**, not a new cognitive architecture. Since the experiment is iteratively tuned after observing failed traces, these training-proximal tasks are no longer independent holdouts. Future claims require a separately authored sealed battery.

## Recollection availability and matched intervention

The early live traces revealed that first-person autobiography was stored but was absent from the generic 14-record subject-context retrieval despite source verification. The approved Doctor Lives cognitive view is now queried using the current qualitative beaker percept as a cue before projection through the existing Subject Interface Firewall. The external world is not permitted to hand the previous answer or hidden simulation state to the decoder. A dedicated test requires source-admitted collection memory to appear on a subsequent wake and disappear when only laboratory autobiography is masked from the subject projection.

When a live first turn causes an independently verified physical action, the runner additionally forks two copies of the same post-action physical ledger and two copies of the same post-action cognitive state. Both arms have the identical currently available legal actions and same underlying neural state. One model sees admitted laboratory autobiography through the subject frame and the other sees that portion withheld. The runner checks that physical epoch, revision, state digest and presented menus match, and records whether the prompt actually differs. If the full arm does not retrieve an admitted lab memory, the comparison is not valid evidence of a memory effect. This narrowly tests the **effect of making authenticated autobiography available to the local language model**, not neural memory ablation or whole-character continuity.
