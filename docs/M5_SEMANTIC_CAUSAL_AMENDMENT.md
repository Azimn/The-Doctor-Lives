# M5 Semantic Causal Normalization Amendment

**Status:** Post-null corrective research candidate, not part of the initial preregistered M5 semantic judge. The initial live source trial found that 20 original Noesis-seeded states showed 8/20 changed native cognitive choices when recurrent weights plus motor readout were neutralized, but **zero of 20** recorded-proposal candidate replay choices changed. The open action selection therefore remained behaviorally insensitive to that lesioned native policy in the tested opportunity set.

**Change:** Retain the original Noesis 10-action scores, but do not treat a uniform action-score floor as action preference. A native semantic class earns a relative recurrent contrast capped at 0.12. The span normalizer is floored at 0.005 to prevent blowing up numerical noise. Other family effects remain capped: novelty +0.05, memory history +0.03, familiarity per family. Exact proposal and decision receipts, cloned neural weights, and all Laboratory action grants remain unchanged. No second model, selector, brain or planner is introduced.

**Independent evidence gate:** Freeze this normalization before measuring again. The existing `scripts/verify_semantics.py` and 20-seed `scripts/m5_attribute.py` must quantify novelty-removal choices and both recurrent-W-only versus recurrent-W-plus-motor lesions, including same-source open intention candidate replay. A change in an *additional cloned-state choice* is not itself physical task improvement. The cheap equal-information baseline must remain in `scripts/m5_donor_ablation.py`. If no causal effect is found, explicitly retain a null disposition. No readjustment of scores or thresholds using observed post-change cases is authorized without a newly versioned study.
