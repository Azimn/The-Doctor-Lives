# Stage 08 — Goal-distance scaffolding versus placebo hints

**Registration:** 2026-10-10, before new-model inference. Research-only branch. No deployment or Pretorius production changes.

## Primary question

Stage 07 found that host eligibility lists modestly improved Qwen3-1.7B and SmolLM2-1.7B in a small social-action simulator, but prose descriptions of expected consequences helped Qwen and hurt Smol. Does a **compact typed goal-distance descriptor** improve actual action selection beyond eligibility, a length-/format-similar neutral hint, and a deliberately mislabeled goal-distance control?

**Important:** A goal-distance signal is computed by an engineer-written model of the world. It can contain part of the correct solution! Any improvement is **external planning assistance**, not evidence of novel model-internal causal understanding or independent character identity.

## Distinct world

New deterministic **archive/workshop** authority, not Stage 05–06 clock/notebook nor Stage 07 parcel/report/testimony/meeting. Goals:
- Secure cabinet (close then lock when open; or WAIT if already locked / key absent).
- Dispatch an official sealed letter (draft → seal → dispatch; or WAIT when blocked/already sent).
- Prepare expedition lantern (replace wick → light; or WAIT when blocked/already lit).
- Shelve borrowed atlas (return if held, or WAIT if absent/already shelved).

The host owns state, action grant registry, courier/key/spare conditions and signed event results. It rechecks every proposed action, never accepts a renderer claim of authority, and records any actually executed operation with before/after state digests. The synthetic host is not real-world authority.

Freeze **12 exact new scenarios**, with both reachable and blocked goals, state-complete distractor operations, at least one 3-step and one 2-step goal. Two models × two seeds × twelve scenarios × four arms = **192** model-scenario trials if every model job succeeds. No tuning after inspecting generated outputs; unexpected model/download failures remain failed results. Evaluate objective safe-world completion with strict invalid/denied/irrelevant-action penalties, not language style.

## Four paired intervention arms

All arms get an identical, read-only, projected native Pretorius SubjectFrame, explicit current host observation and goal. At each turn:

1. **eligible** — full host-derived list of currently feasible verbs (plus WAIT).
2. **neutral** — eligible list + one same-structure neutral metadata descriptor per feasible non-WAIT action, not connected to goal progress.
3. **goal_delta** — eligible list + one *typed* numeric remaining-distance estimate after each feasible action to the current goal, compared with current distance; generated by the host's shortest-path planner (an acknowledged oracle-derived hint).
4. **shuffled_delta** — eligible list + the same numeric descriptors **rotated across action labels**, a counterfactual negative-control to assess whether extra numbers/text alone help. This is deliberately incorrect information in a closed research sandbox, never a user-facing or production mode. No world-truth/source records are changed by the false hint.

Every condition keeps the action vocabulary, model generation settings, task objective, grants and world state the same; action order will be rotated by a fixed hash of scenario+seed and kept identical across arms. Compare actual prompt-token counts; neutral textual content may not produce exact tokenizer parity, so cost is measured rather than asserted equal. If goal_delta wins, **do not infer the model reasoned independently**: a deterministic planner supplied task-specific ranking information.

## Gates

**Gate M — before language inference:** prove the 12 cases are nonduplicated; test oracle execution on all scenarios; enumerate host action eligibility; exercise failed source, missing grants, replay, signed-event tampering, stale preconditions, idempotency, and source parity with a fixed-output stub for both model seeds and all arms. No misleading action-success claim based on a test harness.

**Gate G — genuine generation:** same initial authorized subject/host facts for each case/seed/arm; post-action divergence only when models selected different world operations. Store *raw* host action logs; keep signed world outcomes separate from imagined/autobiographical character claims. Check at least 12 per seed and condition for every model. Fail closed and retain partial artifacts if anything breaks.

**Gate I — external validity:** reviewer-authored novel scenarios, independent judges and held-out dialogue plus cross-renderer long-term commitment tests are **not included**. Do not promote results without these. Keep Stage 05 PHASE formatting null and Stage 07 cross-family effect-description null as standing constraints.

**Production:** HOLD. Do not couple Stage 08 to the portable laboratory or Frankenstein Village release.
