## Three immediate highest-risk seams

1. **Current production access vs opt-in UPPB:** the original `PretoriusBrain.render_request` now constructs a `SubjectFrame`; `render_audit_envelope` keeps diagnostics separate. The optional Synthetic Ipseity adapter documents that a direct renderer/model caller can bypass it. **D3 remains open** until *every default and alternate* model/renderer route is enumerated and tested for prohibited raw fields, internal thought, rereading, self-hearing, tool and hostile-world content.
2. **Single writer means a semantic owner, not a lone Python file:** neural policy and lived memory both reside in original BrainStore; physical book, custody, movement and rhythm are separate independently verified Lab ledgers; host `meta` reservations/goals are privileged engineering state. Verify actual transaction writers, cross-database reconciliation, replay idempotency, and how expected source IDs are authenticated; hashes of attacker-controlled envelopes alone are **not** an authority root.
3. **Native choices vs task agency:** the same-life read->rest CI authenticates two original Noesis decisions and persistent lived consequences, but the host still maps abstract `explore`/`avoid` to fixed goal classes and chooses routes and preparatory cycles. Keep the scientific frozen controls and task metrics separate.
