# D2 implementation: six in-process organ seams

Status: **opt-in, adapter-backed/mapped; not a six-organ production designation**. Changes in PR #89 after baseline main 784cff39d58a7fe46bb5e4ffc16e0284e6663c78.

The new \`doctor_lives/organs.py\` exposes \`SixOrganRuntime\` with six named functional interfaces. All share **one** \`PretoriusBrainPort\`, one canonical \`PretoriusBrain\`, one neural selector, existing SQLite state schema v7 and the same external world authority. The default runtime is unchanged. No separate model, agent, database, scheduler, simulated body physics or Sensus donor was created.

| Organ | Executable existing mechanism through port | Status / missing qualifier |
|---|---|---|
| Noesis | \`deliberate()\` executes the real \`PretoriusBrainPort.cognition\` neural policy; returns a typed **host-initiated cognitive proposal**, never an actuation receipt | Adapter-backed. Native endogenous planning and world action not demonstrated |
| Mnemosyne | \`bind_host_recollection()\` and \`recollect()\` use the **existing one-use, state-bound** recollection controller and typed first-person \`SubjectFrame\` | Adapter-backed. Protected evidence and P4-P6D experimental mechanisms remain separate |
| Affectus | \`read_motivational_influence()\` inspects real current needs-mediated policy deltas without changing neural/action policy | Mapped. Engineer read only; not a separate emotional engine |
| Sensus | \`acquire_existing_percept()\` delegates authorized world/tool percepts to the existing ingress firewall and persists in the one BrainStore | Mapped. **No multichannel binding or standalone donor imported** |
| Synthetic Ipseity | \`project_subject_frame()\` accesses canonical Doctor typed \`SubjectFrame\` prior to any durable outbox | Adapter-backed. Durable optional Synthetic Ipseity requires separately verified integration, global no-bypass unproven |
| Corpus | \`acquire_body_signal()\` admits provider-supplied bodily data through existing interoceptive projector, with raw telemetry excluded from first-person acquisition | Mapped. **No physical action/robot controller or authoritative body store** |

All ingress requires an explicitly opted-in host call. This guard is not cryptographic attestation, and a Python module with accessible object internals is not a security sandbox. An authorized host must authenticate actual provider sources and keep engineering reads off model/tool endpoints. Existing canonical direct ports remain available to other hosts; therefore D3 global no-bypass is **not** complete.

\`AcquisitionReceipt\`, \`CognitiveProposal\` and \`AffectiveInfluence\` are immutable host-only types. The subject representation is provided only by the factory-created \`SubjectFrame\`. The cognitive proposal labels its initiator \`host\`, not Pretorius, and reports a tendency, **not a completed action**. The selected-action evidence remains generated by the original brain. No external hardware action is possible through these ports.

Test coverage in \`tests/test_six_organ_runtime.py\` includes six-port single-owner topology, explicit percept/body channel separation, first-person heard-versus-seen acquisition, hidden sensor telemetry, needs modulation without a second selector, host-initiated Noesis, one brain-bound recollection grant, SubjectFrame privacy and no-donor restart continuity.

**Follow-on gates:** implement verified acquisition/provenance tokens in an authorized host; eliminate subject-access bypass across renderer, private thought and recall; demonstrate causal impact of admitted first-person frames; establish exact write-field ownership; run staged Laboratory parity and mocked alternate body providers; adopt Sensus only after matched multichannel experiment; qualify distinct Affectus/Corpus mechanisms only with intervention tests. Preserve the pre-migration backup and do not merge to main until the D0-D11 checklist and review criteria pass.
