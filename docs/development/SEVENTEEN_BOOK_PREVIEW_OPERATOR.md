# Source-pinned 17-book standalone Laboratory preview (experimental)

This archive is prepared by CI using the exact, separately reviewed
Laboratory, Sensus, Affectus and Ipseity donor revisions. The archive includes
a pristine original 1890 Laboratory with 17 source-verified, full-text volumes,
plus offline wheels for Python 3.12 and an installer. The book snapshot is taken
**before** any host-directed test reading or movement. The rest of the builder's
post-test world is never given to Pretorius as his history.

The Linux and Windows bundles are platform-specific. Install Python 3.12,
unzip the appropriate bundle to a location you control, and run:

```sh
python install.py --install-root /absolute/path/to/new/pretorius
```

On Windows use `py -3.12 install.py --install-root C:\\PretoriusPreview`.

The installation refuses an existing target, verifies every archived file's
SHA-256, creates a clean virtual environment without fetching packages, checks
the installed reviewed donors, and atomically creates the one original Doctor
and pristine 17-book Laboratory workspace. The software is never authorized to
use a fake book ID, synthesize book content, or import post-test memories.

Use `start-preview.cmd` on Windows or `./start-preview.sh` on Linux for
source-backed native book/rest goal opportunities. Use the corresponding
`status-preview`, `stop-preview`, and `resume-preview` launchers. These
commands do not take goals or demand automatic conversational responses.
`preview-resume` resumes the same workspace with the persisted donor source
selection and no new subject instructions.

For auditability, the bundle manifest records all source commits, every
individual archived byte hash and the 17-book builder's acceptance-report
digest. Preserve the downloaded archive and checksum when distributing.

## Limits

The installer has not passed acceptance until its independent, exact-head CI
build/install job is green. The donor source trees are deliberately stored
locally with Git detached-HEAD metadata because the Sensus provenance verifier
requires that form. No runtime GitHub access is used. Source checkouts and the
world's book fixture were engineer-provisioned, so this is not evidence that
Pretorius discovered a library on his own.

The native policy currently maps genuine `explore` choices to book pursuit
and `avoid` choices to rest. The host still selects bounded goal mappings
and physical routes. A third uncoached, materially distinct activity and
the 86,400-second real soak remain separate release gates. No merge, tag,
social chatbot or 1.0 release is authorized by installing this preview.
