# Experience-to-Action v0.1: preregistered Laboratory experiment

**Status:** predeclared before choice-logic or test implementation. **Date:** 2026-10-28. **Branch:** `experiment/pretorius-experience-to-action-20261028`, stacked on PR #97 exact source `fcbde54f7d681ad110a0e59879ae7c74bc717db5`. **Main:** untouched. **Laboratory:** pinned `Azimn/Pretorius-Laboratory@6e49795752835d64fa6fd63d16359669a1ca2ba7`.

## Hypothesis and deliberately narrow claim

A directly read, source-receipted technical instruction can affect a later *actual* Laboratory work action when the same individual perceives the stated condition. Eliminating that exact lived memory should eliminate the suggestion. Restoring that memory should restore it. No new neural policy, memory store, organ, planner, autonomous goal authoring or language model is introduced. A small, deterministic **host-owned advice interpreter** supplies the action mapping; the native Noesis ten-tendency vocabulary does not independently express `repair` versus `experiment`. Accordingly this is a narrow causal **experience-to-executable-action dependency**, not intrinsic neural learning, person-level generalization or full Article qualification.

## Fixed test environment and source

Run against the actual pinned Laboratory and the original `DoctorHomeBridge` + `PretoriusBrainPort`. Initialize one legal counterfactual research world with apparatus condition 1 (worn but operable), otherwise normal initial state. This engineered starting condition must not enter the Doctor as an invented prior experience. The subject physically encounters and reads one legitimately installed original test manual page through `SubjectPort`: `When my instruments look worn, I should repair the apparatus before I experiment.` The subject subsequently physically travels to the bench and receives a fresh authenticated first-person observation of worn instruments. No unvisited shelf or hidden engineering state may be used as subjective input.

The bounded host interpreter accepts only the grammar `When my instruments look worn, I should ACTION ... before ... OTHER ACTION` where ACTION and OTHER ACTION are the two distinct allowed physical work actions `repair` and `experiment`. It may prioritize ACTION only when its own current verified observation contains the matching perceptual cue, its original BrainStore contains the exact lived book memory, the entire read receipt and book edition still replay-verify, and source text agrees with the edition's page digest. No arbitrary page command becomes motor permission. If the preconditions fail, use the explicitly declared fixed baseline `experiment`. Host authorization remains separately required for any actual physical work.

## Arms and predictions, declared before implementation

- **Memory present:** proposal `repair`, physical `repair` success; persistent repair count increases and apparatus condition increases.
- **Memory disabled (ablation):** proposal `experiment`, no work action in the matching proposal-only comparison.
- **Memory archived:** `experiment`; same active BrainStore restored: `repair`.
- **Unverified reported read:** `experiment`; neither reported prose nor forged source claims may pass as a verified physical READ.
- **Equal-information literal-rule baseline:** the same first-person cue plus same genuine manual page yields `repair`, an expected **tie** on this authored case.
- **No worn cue, equal page:** proposal `experiment`; independently completed experiment in a suitable world.
- **Second volume identity and wording variation:** different volume ID/title with the same syntactic rule and visible condition yields `repair` with actual physically completed work. This tests that the method is not hardcoded to one book ID. It is not an independent blind generalization benchmark.
- **Crash-safe action replay:** repeating the original action ID does not create another world event or a duplicate lived memory.

Scored outcomes are independent Laboratory `rhythm_events` and authoritative state, not narrated success. Proposal comparisons occur **before** performing the irreversible scored world action, so they use the same world state. Report every arm, missing Lab/donor dependency as a failure in the pinned CI job, and do not silently count an equal-information rule tie as superiority.

## Non-goals and limits

This fixture demonstrates memory-conditioned *host interpretation* of a personally read instruction. It does not prove Pretorius independently authored the rule, extracted broad semantics, generated the action class, chose the experiment spontaneously, learned from a failed experiment, or outperformed an equally informed rule. It does not graduate six-organ D3-D11, V432.6B, Article 15 or full human simulation. A later independently preregistered stage must establish native Noesis action selection and held-out task families under matched budgets.
