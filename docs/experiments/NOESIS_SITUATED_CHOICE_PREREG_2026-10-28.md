# Noesis-owned situated work selection v0.2: preregistration

Date: 2026-10-28. Status: fixed experimental protocol before v0.2 implementation. Scope: extend draft PR #98 only, do not change production main or the default ten-tendency policy.

## Claim under test

The *canonical Pretorius brain*, reached through `NoesisOrgan`, can compare actual currently feasible Laboratory work actions using its existing recurrent action tendency scores and *source-qualified first-person learned evidence*. The final `repair` versus `experiment` action is selected and recorded **inside original Noesis / original BrainStore**, not by the external host grammar interpreter. The host checks physical feasibility and source receipts, exposes offered action identities and eligible autobiographical memory IDs, and separately authorizes execution. It never supplies desired action or score.

This is narrow **instruction-conditioned Noesis choice**. Reading a manual and using its explicit instruction is not equivalent to discovering new causal knowledge, acquiring procedural motor competence, optimizing from trial outcomes, or general-purpose natural-language reasoning. The handwritten parser belongs to Noesis as a cognitive mechanism; the action grounding `explore -> experiment` and `persist -> repair` is predeclared, not itself learned.

## Frozen decision rule

Given the original brain's own recurrent ten-tendency probabilities, derive concrete-action priors with the fixed two-action mapping noted above (no second neural substrate). Use an additive *at most +0.6* memory contribution from one directly read active lived Laboratory book memory if its own previously admitted first-person content contains a matched bounded conditional instruction. The instruction must match a current first-person observation cue. No source- or event-IDs, numeric physiology, raw page, or desired choice are ever given to the renderer. No memory can authorize physical action. The choice must be logged as a `noesis-situated-choice-v0.2` policy decision and thought in the **existing BrainStore** with neural baseline, concrete candidate scores, eligible source IDs and the selected concrete action.

A purely reported book claim, archived book experience, nonmatching condition, instruction referring to unavailable actions, or absent world source verification cannot contribute evidence. Host source-verifies candidate read memories using the original Laboratory's receipt and page digest. Noesis retrieves their stored first-person text independently.

## Controlled arms

1. Worn apparatus, genuine physically read conditional instruction, original Noesis candidate ranking. Expected: **repair wins** and the original Laboratory executes one independently verified repair when authorized.
2. Same history, **learning evidence disabled**, same native neural state and offered alternatives. Expected: instruction contribution is zero; audit reports zero contributed evidence. A changed final action is a stronger causal result but is not guaranteed by all neural seeds.
3. Same world with the exact instruction memory archived and subsequently restored. Expected: source-dependent Noesis score delta disappears/reappears, with the original world unchanged.
4. Same true world but only unverified reported instruction. Expected: no instruction contribution. No false lived memory.
5. Two distinct real installed manuals, both source-backed. Noesis may process only matching, available firsthand contents, and last relevant direct evidence has a fixed priority. Never select from an unread book.
6. New source-backed book identity and varied wording, same meaning, tests non-ID specificity, not blind generality.
7. Unworn apparatus with the same genuine read. Expected: no conditional contribution. Actual unmodified Laboratory feasibility restricts candidates; no fabricated actions.
8. Unauthorized action must not commit. Authorized execution must produce real Laboratory receipt and one original lived memory. Repetition and restart must not duplicate world action or memory.
9. Neural prior ablation: hold memory and offers identical, perturb **only** the native recurrent motor prior with an explicit injected research control or matched distinct seed. Audit must report a concrete-score change. If learned evidence overwhelms prior so selected action stays fixed, do **not** claim neural policy selection is causally necessary.

## Scientific limitations and passing gates

A green test suite proves only narrow engineered functional behavior. Noesis must own the action winner and the policy decision, without host picking it. Laboratory history must remain authoritative and first-person. Show causality on *internal score* with memory lesion and optionally on *action* for tested seeds. Preserve simple equal-information rule as parity baseline and report ties honestly. Hold out untested generalization, Article 15, general agency and full six-organ graduation. Existing PR #98 v0.1 host interpreter remains an explicit baseline only, not called by v0.2 Noesis choice.
