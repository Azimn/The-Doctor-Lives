# Portable Life AI: game simulation mechanisms for Pretorius

Date: 2026-10-16. Status: opt-in experiment. Production default unchanged.

## Why

The real Sims-inspired home-motive queue already exists. Its authored four-situation pilot measured native policy 1/4, native with bodily motives 3/4, motive ablation 2/4, and a strong simple controller 4/4. Rest before repairing worn equipment in the hybrid case was defensible because the experiment setup also created fatigue. This is not a human-likeness or Article qualification test.

The new portable game-AI kernel in doctor_lives/portable_life_policy.py has no environment imports. The original Pretorius brain remains owner of identity, memories, values, goals, recurrent neural state and relationships. The kernel merely ranks currently perceived, externally authorized opportunities based on current motive pressure, goal relevance, expected benefits, costs, native neural preferences, weak persistence of the prior strategy, and source-verified learned procedural tendencies. It cannot directly act or create autobiographical memories. Actions advertise environment-independent strategies rather than binding cognitive goals to room-specific commands.

The opt-in doctor_lives/portable_doctor_adapter.py requests *real* Doctor cognition after source-backed first-person observation. It returns advisory audit results only. A trusted environment adapter must source offered action affordances and goal/motive signals from Pretorius's permitted access, never privileged facts about things he cannot see. The first-person string shape alone is not proof of authenticity. A callable verifier must authenticate each world receipt before the procedural cache learns. This design is **not** an independently verified new source authority.

## Test evidence and boundaries

The pure policy suite includes cross-domain goals, competing motive counterfactuals, restart persistence, procedural success and failure, ablation of native contributions, input validation, anti-omniscience controls, receipt idempotence, and 240 seeded motive-pair counterfactuals across four domain names. Synthetic domain labels can demonstrate the same computation operates outside the Laboratory, but not that Pretorius independently understands a new context.

The adapter unit suite tests real Doctor port shapes using controlled fake sources. A separate pinned-Laboratory CI test uses an actual PretoriusBrainPort, its verified first-person home bridge, a real native neural policy decision, an authorized physical action and the independent Laboratory's durable receipt for procedure learning. This is one authored wiring test, not independent social autonomy.

Local pure tests passed 16/16 on October 16, 2026. The linked GitHub Actions matrix and pinned Laboratory integration must pass independently before considering merge.

## Next discriminating experiments

Freeze independently authored real-world scenarios and varied seeds before tuning coefficients. Compare unchanged native Doctor, existing home-motive hybrid, portable hybrid, no-learning/no-inertia/no-neural lesions, and a strong cheap controller. Give comparable permitted first-person information and action/computation budgets. Measure goal completion across time, interruptible multi-step plans, physically verified opportunity costs, consequences, and deviations, not merely agreement with an expected first verb.

Add withheld room states; equipment wear without fatigue; fatigue without equipment wear; both pressures together; scarce tools; a promise interrupted by bodily demands; a misleading correspondent; re-planning after a genuine change; newly learned skills that should not transfer; and different life histories using identical base neural checkpoints.

Independent assessors should rate observed behavior with real causal consequences while blinded to architecture. Keep first-person ingress, source authority, actual Doctor identity, and renderer neutrality intact. Do not equate plausible narrated introspection with causally grounded character behavior.
