## Start and operate

Install the existing Doctor and pinned original Laboratory wheels from the verified offline wheelhouse. Prepare the canonical BrainStore and original Laboratory world using the existing setup and recovery process. The following commands require those existing paths and never create a second mind or imaginary world:

```text
doctor-lives --state ./brain lab-start --world ./laboratory.sqlite3
doctor-lives --state ./brain lab-run --world ./laboratory.sqlite3 --seconds 60 --interval-seconds 5
doctor-lives --state ./brain lab-run --world ./laboratory.sqlite3 --seconds 60 --interval-seconds 5 --work-every-seconds 15
```

The first `lab-run` only observes and schedules native cognitive pulses. The opt-in third command offers bounded work opportunities at real monotonic-clock intervals. If Pretorius is not physically at the original Laboratory bench, the host does not move him or perform work. At the bench, the host supplies all physically feasible experiment/repair options and authenticated lived memory IDs to original recurrent Noesis. Only Noesis selects an action; the original world checks feasibility and commits physical effects; the existing bridge authenticates the receipt before autobiographical admission. Operator-visible JSON `work_events` records event ID, chosen action, status and selector, not neural scores or raw world telemetry. UTC ISO-8601 and Swatch @beats are reported for display; neither replaces monotonic elapsed scheduling.

A graceful SIGINT/SIGTERM stops new opportunities and checkpoints the original brain. Reopen with `lab-start` and `lab-run`. The existing recovery protocol reconciles only already authorized original-world receipts and does not repeat abandoned actions. For backup or restore, use existing `lab-backup` and `lab-restore` commands; never copy an active SQLite world and brain by hand.
