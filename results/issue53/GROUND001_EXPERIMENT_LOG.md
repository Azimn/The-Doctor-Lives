## Semantic operation-and-operand tokens

The exact-match form OBSERVE|floor:sanctum, COLLECT|beaker:001 and PLACE|beaker:001|floor:corner:nw represents the entire proposed host operation, including each operand, as a single selectable token. The language model must pick the token. The adapter cannot supply missing parts or replace a malformed decision with a scripted action. The host reauthorizes independently.

Run https://github.com/Azimn/The-Doctor-Lives/actions/runs/38093171028 generated five successive valid OBSERVE|floor:sanctum choices without any physical glass progress. Every observation was admitted as a distinct receipt. The simple nonneural planner again succeeded. This is a strong negative result for goal relevance and action repetition, not a syntax failure.

A separate defect was discovered in the accepted subject-context retrieval: although the earlier action was committed to lived memory, generic top-record retrieval did not reliably present it in the returning subjective frame. The adapter now cues only the existing Pretorius cognitive view with the CURRENT qualitative beaker percept and retains the UPPB/source-admission boundary. A dedicated restart test requires source-admitted collection memory to appear after restart, and a paired mask removes lab autobiography without touching the underlying brain. This is a retrieval correction, not an additional memory authority.

## Public action semantics

Stage 07 had previously observed a limited Qwen improvement from 6/12 to 7/12 on one social-goal bank when public effect semantics were added to eligibility, but SmolLM2 declined from 4/12 to 3/12. There is no general superiority claim. In the present glass task, an initial effect-display treatment joined descriptions to selectable tokens. Qwen selected a valid inspection token with bare menu labels but copied the entire descriptive line under the effects treatment, resulting in a rejected invalid proposal. The matched comparison is recorded in https://github.com/Azimn/The-Doctor-Lives/actions/runs/38093675654. The resulting code now puts effect definitions in a separate glossary and reserves a separate bare-token selection menu.

A safety watchdog also stops the bounded research runner after the same non-mutating observation is selected twice against an unchanged physical state. It never changes the model's chosen operation or supplies a fallback plan. The seven dedicated contract tests at the GROUND-001 research head have passed, including source-safe lived recollection, masked autobiography, effect-menu parity and the stagnation detection contract.

## Remaining experimental gate

The latest paired effects-versus-names, actual local-model run must decide whether the isolated effects glossary improves first-step relevance or end-to-end task performance. The runner also forks identical world and brain state after an independently executed first physical act, running the exact same model with visible versus masked laboratory autobiography. If no admitted autobiography is actually present in the full subject frame, the control reports an invalid exposure contrast. Neither presentation test proves causal recurrent-neural memory benefit.

These runs are researcher-authored, adaptively revised after observed failures, and not an independently sealed benchmark. A goal-relevant action must be chosen by the real model, not a deterministic goal-distance planner masquerading as Pretorius. The nonneural control remains a strong comparison. The authorization, provenance, snapshot, no-unread-book-knowledge and subject-firewall rules remain intact. There is no defensible claim yet of open-ended character autonomy or neural efficacy.
